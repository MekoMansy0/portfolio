# makarymansy.com

My personal portfolio site, showcasing my projects in hardware, firmware, and software.

Built as a single self-contained HTML file and hosted with GitHub Pages.

## About

This site was made by me (Makary Mansy) together with Claude (Anthropic's AI), and honestly, it was vibecoded. I knew the look and feel I wanted, bounced ideas back and forth, and we built it out from there until it felt right.

## Tech

- Plain HTML, CSS, and a little JavaScript, no frameworks
- Single file, assets embedded inline
- Hosted on GitHub Pages
